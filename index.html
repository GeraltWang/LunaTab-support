隐私政策

生效日期及最后更新：2026 年 10 月 12 日

本政策适用于 LunaTab 浏览器扩展。LunaTab 的用途是在新标签页中管理你保存的网页、文件夹、布局和小组件， 并提供搜索、书签导入、本地备份及由你选择启用的 WebDAV 备份与同步。

工作区数据默认保存在本机。LunaTab 没有开发者运营的账户、数据上传、广告或使用统计服务。 网站图标会从其来源网站加载；网页搜索使用你选择的搜索引擎，提交的关键词会发送到相应搜索服务； 只有你主动连接 WebDAV 后，备份或同步数据才会发送到你指定的服务器。

1. 处理哪些数据及其用途

  • 工作区内容：你输入或导入的书签网址、标题、图标与裁剪配置、保存时间、文件夹、归档内容、分页、 布局、小组件配置和偏好，用于显示、组织、搜索与恢复你的工作区。
  • 打开书签的时间：记录你从 LunaTab 打开某个书签的时间，用于旧书签回顾及同步书签状态。 关闭“旧书签回顾”会停止回顾提示，但不会停止书签打开时间的记录。
  • 当前网页和图标：你打开工具栏弹窗时，扩展使用临时的当前页权限读取网址、标题及网页声明的图标信息，以便保存书签。 在新标签页添加或编辑书签时，通过网址发现图标需要先授予目标网站访问权限； 扩展会解析返回的网页 HTML，仅提取图标地址、类型及尺寸等信息，不保存整页 HTML。 图标图片的加载和显示适用下文所述的网络请求规则。 扩展不会在后台遍历标签页或建立浏览记录库。
  • 导入内容：仅在你点击读取 Chrome 书签并授予权限，或选择 HTML、Infinity 或 LunaTab 备份文件后， 读取相应书签、文件夹和受支持的配置，用于导入预览与恢复；文件在本机解析，不上传原始文件。 导入后的工作区内容适用你已开启的 WebDAV 备份与同步设置。
  • 随机标识：本机生成的身份 Token 和头像种子用于显示本地用户信息，不是登录账号或认证密钥， 不发送给开发者，也不进入工作区备份。另一个随机设备标识用于区分 WebDAV 设备文件， 会随远端备份、同步元数据发送到你指定的服务器；它不使用硬件序列号或浏览器指纹。
  • WebDAV 连接信息：你填写的服务器地址、用户名和密码用于验证、备份、下载及同步。 连接信息保存在本机扩展存储，不包含在导出的备份或远端工作区文件中；认证请求会将用户名和密码发送到你指定的服务器。
  • 本地运行状态：引导完成状态、适配布局的行数、本地历史快照及同步版本、冲突、删除记录等元数据， 用于保持界面状态、恢复内容和协调多设备同步。同步所需的元数据会发送到已连接的 WebDAV 服务器。

LunaTab 不读取 Chrome 的完整浏览历史，不采集无关页面的正文、表单输入、密码或私人通信， 不添加统计 SDK、跟踪像素、广告标识或用于广告的 Cookie。你自行保存或导入的内容仍可能包含个人信息， 请按其敏感程度管理书签、备份与服务器访问权限。

2. 网络请求与数据接收方

网站及图标来源

首次获取某个网站的图标时，你需要点击“获取网站图标”并授予该网站的访问权限； 以后填写或编辑已授权网站的网址时，会自动请求该网页以发现图标。 未授权时不会请求网页，你仍可保存文字图标书签。工具栏弹窗使用临时的当前页权限读取声明的图标。 加载、检查或显示网站图标时，目标网站及其声明的图片服务器或 CDN 会收到请求 URL、IP 地址及常规 HTTP 请求信息。 已保存的网站图标可能在以后打开新标签页时继续加载，并会在本机缓存缩略图。 通过网址获取网页和生成图标缩略图的请求使用 credentials: omit，不携带网页登录凭据； 图片显示及尺寸检查使用普通图片加载，适用浏览器的网络、Cookie 及网站规则， 不为图片来源或 CDN 额外申请网站读取权限。LunaTab 不把你的全部书签列表发送给图标服务。

搜索引擎及打开的网站

匹配已保存书签的搜索在本机完成。只有你提交网页搜索时，关键词才通过搜索 URL 发送给所选的 Google、Microsoft Bing 或百度，支持网页、图片、视频、新闻和地图分类。 引擎偏好在本机保存，并随工作区备份和多设备同步。LunaTab 不修改浏览器的默认搜索设置， 不提供远端搜索联想，不向开发者发送或持久保存搜索词。 打开搜索结果或书签后，对应网站会按正常浏览方式处理网络信息、Cookie 和内容。

搜索服务分别适用 Google 隐私政策、 Microsoft 隐私声明和 百度隐私政策。 图标服务及你打开的其他网站适用各自的隐私政策。

你指定的 WebDAV 服务器

此功能默认不连接任何服务器。首次点击“验证”或“连接”时，先申请你指定服务器的网站访问权限； 拒绝授权不会发送凭据。授权后点击“验证”会发送认证信息，检查或创建 LunaTab 目录并读写、删除测试文件； 点击“连接”还会在本机保存连接信息，并自动上传本机工作区历史快照。 开启“多设备同步”后，工作区内容、布局、打开书签的时间及同步元数据会自动与同一目录下的设备交换。 服务器运营者及具有该目录访问权限的人可能读取这些文件；其保存、日志、处理地区及隐私规则由你选择的服务决定。 LunaTab 开发者不作为中转方接收这些数据。

工作区备份与同步文件不含 WebDAV 密码、本地身份 Token 或头像种子。 备份和同步文件没有端到端加密，完整性校验不等于加密；请使用可信的服务器、受限的目录权限和专用凭据。

联系支持及政策网页

你主动联系开发者时，接收方会收到你提交的联系方式、问题和附件，仅用于处理请求。 请不要发送密码、身份凭据或含私人信息的完整备份。 扩展内的隐私政策可离线阅读，不加载外部脚本、字体、图片、分析服务或 Cookie。 公开版本由 GitHub Pages 托管。通过该网站阅读时，GitHub 会收到页面 URL、IP 地址及常规页面访问和服务器日志信息， 按 GitHub 隐私声明 处理。开发者没有为该页面添加访问统计。

3. 为什么需要这些权限

  • storage：在本机保存工作区、偏好、历史、随机标识及你填写的 WebDAV 连接信息。
  • activeTab：你点击扩展工具栏时，读取当前网页的网址和标题以创建书签。
  • scripting：在你打开工具栏弹窗后，在当前网页运行随扩展打包的代码，读取声明的网站图标。
  • bookmarks（可选）：仅在你主动读取 Chrome 书签时申请，用于读取书签树和导入预览， 不修改或删除 Chrome 原有书签。
  • HTTP / HTTPS 网站访问（可选）：安装时不授予所有网站访问权限。仅在你点击获取网站图标或验证、连接 WebDAV 时， 申请当前选择的协议及主机名，不申请全部网站或子域。 Chrome 网站授权覆盖该主机的所有路径和端口，不能限制为某个 WebDAV 目录； LunaTab 的 WebDAV 请求仍只访问配置目录中的 LunaTab 文件。 普通图片显示不需要此权限。普通网址和图片可能使用 HTTP，传输不受 TLS 保护；请优先使用 HTTPS 来源。

你可以在 Chrome 的扩展管理界面撤销已授予的网站访问或可选书签权限。 撤销网站权限后，网页图标发现停止；WebDAV 认证请求在发送前检查授权，授权缺失时停止传输并提示重新连接。 LunaTab 使用随扩展打包的代码，不下载或执行远端脚本；远端网页和 WebDAV 文件作为数据处理。

4. 保存期限、访问与删除

  • 本机内容：存于当前浏览器配置文件的扩展本地存储（chrome.storage.local）， 图标缩略图存于该扩展的 Cache API 缓存。工作区会保留到你更改内容或移除扩展。 当前本地普通历史保留最近 3 份快照，旧快照在新增时轮换。全设备恢复前的内容与其他设备的未同步修改会保存为独立同步保护副本，不自动清理，可在本地历史中导出或手动删除；不再使用的图标缩略图会在缓存整理时移除。
  • 远端内容：普通 WebDAV 历史每台设备保留最近 3 份，在成功上传并清理时轮换。 同步状态文件、全设备恢复标记以及同步前的保护快照不受这个 3 份限制，可能继续包含旧内容、删除记录或冲突数据。 服务器自身的备份及日志遵循服务提供方的规则。
  • 访问和导出：你可以在扩展中查看及编辑工作区，在“设置 → 备份”导出 LunaTab 备份或 HTML 书签文件， 并查看本地和已连接的远端历史。同步开启时，从文件、本地历史或远端历史恢复会让所有同步设备采用选定备份；需要联网，其他设备在下次同步时应用恢复并先保护未同步修改。关闭同步后恢复只影响本机。导出的文件由你控制，没有额外的应用层加密。
  • 支持问题：你主动提交的公开 Issue 和评论保留在 GitHub 支持仓库，直至删除或按平台规则处理。 你可以编辑自己提交的内容、删除自己的评论，并请求维护者删除相关 Issue。 GitHub 另行保留的副本及服务日志适用其隐私声明。
  • 停止远端传输：在“设置 → 备份”关闭多设备同步可停止该同步功能； 已连接时，远端历史备份仍会运行。关闭 WebDAV 连接会停止后续备份与同步，移除本机保存的连接地址、用户名和密码。 断开连接不会删除本地工作区、随机设备标识或已上传文件；浏览器已授予的网站权限仍保留， 可在 Chrome 扩展管理界面撤销，同一站点的图标获取也可能使用该授权。 仅验证但没有连接时，凭据不会保存到扩展存储，当前表单中的输入保留到你清空或关闭设置。
  • 完整删除：归档或从当前工作区移除内容不代表历史快照中的副本已删除。 如需移除全部数据，请先在每台已连接设备上断开 WebDAV，卸载扩展以移除该浏览器中的扩展数据， 并自行删除导出文件及 WebDAV 的 LunaTab 目录中的历史、同步状态、恢复标记和保护快照。 服务器额外保留的副本或日志请向服务提供方申请删除。开发者无法代你访问或删除这些本地及远端文件。

5. 数据安全

远程 WebDAV 连接必须使用 HTTPS；仅 localhost 和 127.0.0.1 本机测试允许 HTTP。 WebDAV 通过 HTTP Basic Authentication 在该连接上传输凭据；HTTPS 提供传输加密。 WebDAV 请求不携带网站 Cookie，并拒绝重定向；如服务地址重定向，请使用最终的 HTTPS 目录地址。 扩展本地存储仅允许扩展的可信上下文访问，不向网页内脚本开放。 本地扩展存储、导出文件和 WebDAV 文件没有额外的应用层加密，扩展没有把密码保存到系统密码保险库。 其安全性也取决于设备、浏览器配置文件、服务器及访问权限的保护。

请选择可信服务器，保护设备和备份，使用专用或应用密码，并避免保存不必要的敏感信息。

6. 数据用途及 Limited Use 声明

LunaTab 对用户数据（包括通过 Chrome / Google API 获取的信息）的使用遵守 Chrome Web Store 用户数据政策， 包括 Limited Use 要求。 数据仅用于本政策所述的新标签页工作区功能及其必要运行。

LunaTab 不出售用户数据，不向广告平台、数据经纪商或信息转售商提供数据， 不用于个性化广告、信用评估、贷款或与扩展用途无关的分析。 开发者不通过扩展访问你的本地或 WebDAV 工作区；如为支持请求需要查看特定内容，会先征得你的明确同意， 并仅使用你主动提供的必要信息。其他依法要求的处理也受适用法律及上述政策限制。

7. 政策更新

功能或数据处理方式变化时，我们会更新本政策和日期，并保持 Chrome Web Store 隐私披露与实际行为一致。 如新增数据用途、接收方或权限，会在相关处理发生前按要求在扩展中明确说明并取得必要授权。

8. 联系我们

LunaTab 由 GitHub 用户 GeraltWang 提供和维护。有关本政策、数据处理或隐私请求， 请通过 LunaTab GitHub Issues 联系发布者。阅读支持页面无需登录；提交问题需要 GitHub 账号，并适用 GitHub 的隐私规则。

Issues 是公开的，请仅说明扩展名称和请求类型，不要提交密码、联系方式或未经脱敏的私人数据。 如请求需要提供私人信息，请先询问合适的私密联系渠道，再经双方确认提供最少必要信息。

本政策仅描述 LunaTab 扩展的数据处理，不替代你选择的网站、搜索引擎或存储服务的隐私政策。
